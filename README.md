Code related to NITARP Educator Research Project: MORIA.

These notebooks are part of extending the teacher research internship experience into the classroom.

## Research Abstract
The Euclid Quick Release 1 (Q1) includes a catalog of AGN as one of its preliminary
data products. This catalog is missing AGN sources that are included in other catalogs,
particularly the WISE AGN catalog. The Euclid team released a preliminary analysis of the
Euclid AGN source catalog compared to other known AGN source catalogs. We will initially
compare the Euclid Q1 AGN catalog with the WISE AGN catalog. This research will use data
analysis and statistical modeling to probe both the overlap and gaps between the Euclid Q1 AGN
catalog and other AGN catalogs.
